# 応募進捗 v0.1：Google Sheets標準コンボグラフ

- 対象：既存の `tsicb/valid-app-sheets`（コンテナバインドGAS）。
- 変更日：2026-10-16
- 状態：**GitHubコード実装・架空データとGAS模擬環境のテスト実施済み。実Google Sheetsでの実表示は未確認**。
- 入力：保存済み `20_突合データ` と `30_分析設定`。**CSV再取込は不要**。
- Web版参照：`tsicb/valid-app/analysis-core.js` の `buildMonthProgress()`、`report.html` の `buildMonthProgressChartHtml()`。

## 使い方

1. スプレッドシートのApps Scriptエディタで `09_ProgressCore.gs`／`10_ProgressSheet.gs` を**新規追加**し、`01_EntryPoint.gs` を最新版に**差し替える**。
2. 保存してスプレッドシートを再読込し、メニュー「有効応募分析 → 応募進捗を再集計」を実行する。
3. `41_応募進捗` に最新月のグラフ、月別の応募数・ターゲット応募数・ターゲット率が表示される。
4. `30_分析設定!B28`（日別／累積）、`B29`（着地予測ON／OFF）、`B30`（比較グラフの月数）を切り替える。これらの3項目は**グラフ参照セルの式で即時切替**し、GASを再実行しない。
5. `30_分析設定!B5:B6` の期間、`B9:B10` の対象年齢、`B13:B14` のターゲット年齢を変更したときは**「応募進捗を再集計」が必要**（CSV再取込は不要）。`41_応募進捗!A6` に未反映を表示する。

## Web版から継承する計算の要点

- **最新月は今日の月ではなく、指定期間に属する実際の応募データの最新月**。直近の応募が2026年9月なら、現在の日付が10月でも2026年9月が最新月。
- 最新月の**最新観測日**は、集計対象年齢に適合しない応募を含めた、指定期間内の最新応募日付。実際に棒に積み上げる件数は年齢フィルター済みの応募に限る。これにより「最新月」の進捗と「対象年齢」による件数が区別できる。
- 31日を横軸にする。月末までのデータが未観測なら**最新月は最新観測日の翌日以降を空白**にし、ゼロ件として見せない。過去月は対象期間とその月の日数に含まれる日に0件を持たせる。
- **日別モード**：最新月を棒、過去月の同一月内日を折れ線で比較。
- **累積モード**：最新月累積を棒、過去月累積を折れ線。予測ONなら現在月の最後の実績点から月末までを予測線として表示する。
- 比較月はWeb版と同じ**前月・前々月・前年同月**の固定3種類。設定B30に1～3を入力すると、この順で表示本数を制限する。独自に「過去Nか月」を補充しない（例：B30=2→前月・前々月）。比較月が指定期間にまったく重ならないときは空白。
- 月間着地予測（最新観測日が月末前のみ）：
  `最新月の観測済み累積応募数 / 観測日数 × 最新月の暦日数`。小数第1位まで。観測日数は指定期間の集計開始日が最新月内の場合、その日から最新観測日まで。選択期間で月が途中から始まる場合も、Web版に合わせ月全体の日数へ外挿する（推定であり確定値ではない）。
- 最新月が月末まで観測されていれば着地予測は表示しない。
- ターゲット応募数は基本分析と同じターゲット年齢条件を利用し、年齢不明はターゲット対象外。月別表は応募年月、応募数、ターゲット応募数、ターゲット率の4列。
- 指定期間に有効な応募日付がなければ空表示にする。元のCSV行は削除しない。

## Google Sheets側の配置

| 場所 | 役割 |
|---|---|
| `41_応募進捗!B3` | `30_分析設定!B28` を参照する読取専用式。入力場所は設定タブに統一。 |
| `41_応募進捗!D3/F3/H3` | 最新月実績／着地予測／比較月についての案内。F3は予測ON/OFFに連動。 |
| `41_応募進捗!A6` | 応募進捗の最終更新・未反映表示。 |
| `41_応募進捗!A7:L24` | Google Sheets標準のコンボチャート配置。棒＝最新月、線＝過去月・予測。 |
| `41_応募進捗!A28:D...` | 月別応募数・ターゲット応募数・ターゲット率。全期間のデータ月数分、行数上限なし。 |
| `41_応募進捗!F28:K59` | **グラフの数式参照元**。31日×6列。データが確認できるよう明示して残す。 |
| `91_進捗キャッシュ!A1:J32` | 内部：日別・累積・予測・比較用の数値データ。以前の4列ヘッダーを**この非表示キャッシュだけ**10列に置き換える。 |

進捗グラフには固定タイトル `応募進捗｜最新月と過去月` を使用する。再集計では同タイトルの自動グラフを**更新**し、重複して増やさない。他のユーザー作成グラフは削除しない。

参照したGoogle Apps Script APIでは、埋め込みグラフの `clearRanges()`／`setChartType()`／`setNumHeaders()`／`setOption()`／`Sheet.updateChart()` がサポートされる。ただしGoogle Sheets本番環境のコンボ系列・予測線の見え方は実機で検証が必要。

## 設定変更の反映方式

| 設定 | 再集計 | 理由 |
|---|---|---|
| `B28` 日別／累積 | 不要 | F28:K59の数式で切替 |
| `B29` 予測表示 | 不要 | 予測系列とF3の数式で切替 |
| `B30` 比較月数（1～3） | 不要 | 前月・前々月・前年同月の数式を表示／空欄化 |
| `B5:B6` 期間 | 必要 | 最新月・対象期間の母集団が変化 |
| `B9:B10` 対象年齢 | 必要 | 月内の棒の件数が変化 |
| `B13:B14` ターゲット年齢 | 必要 | 月別一覧のターゲット件数が変化 |
| CSV全件更新 | 必要 | 保存された応募明細自体が変化 |

`基本分析を再集計`と`応募進捗を再集計`は現在それぞれ独立したコマンド。後続工程で必要なら「分析設定をまとめて反映」コマンドを追加する。
