# TOP画像・Indeedタグ 専用集計 v0.1

- 対象：既存の `tsicb/valid-app-sheets`（Google Sheets・コンテナバインドGAS）
- 実装日：2026-10-16
- **状態**：GitHub実装・架空データ／GAS模擬テスト通過。**実Google Sheetsでの表・画像・Worker通信は未検証**。
- 参照：既存Web版 `tsicb/valid-app/analysis-core.js` の `aggregateTopImages()`／`aggregateIndeedTags()`、`index.html` の固定用途の画像Worker。
- **CSV再取込・テンプレート再生成不要**。応募正本 `20_突合データ`、求人正本 `93_求人分析マスタ` は読取専用。

## 2. 実行順

1. 「有効応募分析 → TOP画像・Indeedタグを再集計」を実行する。
2. `43_TOP画像`・`44_Indeedタグ` の集計結果を確認する。画像URL未取得でも数値は出る。
3. 必要に応じて「TOP画像URLを取得」を実行する。1回につき **最大20画像名** の未試行候補を処理して、既存の `94_画像マスタ` C:E にURL・状態・取得日時を書き込む。画像式は再集計済みの `43` に反映する。
4. 20種類を超える場合、同じメニューを再実行して続きから取得する。失敗した候補が後続の未取得候補の処理を妨げない。
5. 「取得失敗した画像URLを再試行」は、取得失敗・画像なしを含む未解決分の再試行用。成功済みURLは再取得しない。

**Workerは固定URL** `https://tenichi-image-proxy-test.tkarasa.workers.dev/` を使用。Web版と同様、`?jobId=数字` を渡す。任意の求人URL／ユーザー任意URLはWorkerへ渡さない。取込時に `公開情報区分=6` の数値求人管理IDだけを `94` 候補IDとして保存する既存ルールを維持する。

Worker未到達、公開求人なし、画像URL無効は画像表示の失敗として扱い、**応募・求人件数の集計成功とは切り離す**。HTTPS以外、認証情報付き、ローカルアドレス、引用符／制御文字入りURLはシートの `IMAGE()` 数式に使用しない。元の画像マスタのA:Bは書き換えない。

Google Apps ScriptのWebアクセス許可が初回求められる可能性がある。外部HTTP通信を使うのは画像URL取得メニューだけであり、`onOpen`／`onEdit`／通常の専用集計はWorkerへアクセスしない。

## 3. 集計ルール

- 対象は `20_突合データ` の求人CSV突合フラグが真、かつ `93_求人分析マスタ` のソースが `JOB_CSV` の応募のみ。応募CSVの埋込求人情報から画像やタグを推測しない。
- `30_分析設定` B5/B6（集計期間）、B9/B10（対象年齢）、B13/B14（ターゲット年齢）を適用。年齢不明は、年齢範囲指定時は除外し、ターゲット応募数には含めない。
- 1求人に複数応募があれば、画像・タグの各カテゴリには応募件数を加算する。`対象求人数`はカテゴリ内のユニーク `求人参照ID` 数。
- 画像はメイン画像ファイル名別。画像未設定は `（TOP画像なし）` として独立集計し末尾に置く。
- Indeedタグコードは `::` 区切り。**同一求人内の同一タグ重複を除去**する。一応募に複数タグがあれば各タグの応募数に1件ずつ加算する。未設定は `（タグなし）` として末尾に置く。したがってタグカテゴリの応募数合計は応募総数と一致しない。
- `31_マスタ編集` のI=タグコード、J=名称、K=有効チェックを使用。有効名称がないコードは `コード（名称未登録）`。有効な同一コードが複数行にある場合はエラーとする。**コードを伏せたり、行を除外したりはしない**。
- ターゲット率はカテゴリ別の `ターゲット応募数÷総応募数`。割合の平均を使わない。年代列は固定8列（10代～70代＋その他）。
- 指標の全カテゴリを出力し、任意の上位50件・100件には切らない。行追加で全スプレッドシートの1,000万セル上限に触れる場合は表示途中の黙った切捨てをせず、開始前に中止する。

## 4. 表示タブ

- `43_TOP画像!A8:N8`：画像／画像ファイル名／対象求人数／総応募数／ターゲット応募数／ターゲット率／10代～70代＋その他。実データは9行目から。画像URLがあり安全なHTTPS形式であればA列に`IMAGE(URL,4,80,120)`を設定。失敗・未取得なら空画像のままB列以降は有効。
- `44_Indeedタグ!A8:N8`：タグコード／タグ名称／対象求人数／総応募数／ターゲット応募数／ターゲット率／10代～70代＋その他。実データは9行目から。タグコードは文字列として出力し、先頭ゼロを保持する。
- `43!B3`／`44!B3`：再集計済み／条件変更あり・未反映／取込更新後・未反映などの状態。`43!H3`：画像取得の成功数・未取得数。
- `44!A5`：複数タグによる重複計上を常時説明する。
- `30!B33/B34`：それぞれ43/44タブの表示・非表示を制御する。**非表示でも集計数値は保持し、求人や応募の正本は編集しない**。
- 出力時に上書きするのは両タブの9行目以降のデータ領域と必要な説明セル。列幅・背景色・罫線は原則保持。古いカテゴリが減った場合、残余セルの内容をクリアする。

## 5. 集計の再実行・復旧

- CSV全件更新後・期間や年齢条件を変更後・タグ名称マスタ変更後は「TOP画像・Indeedタグを再集計」が必要。**CSV再アップロードは不要**。
- 画像URLだけ取得した場合は集計済みの画像グループにサムネイルだけ更新できるため再集計不要。画像なしでも集計完了扱い。
- 出力開始前に専用集計の「反映済み」状態を無効化する。GASの途中エラーで部分表が残っても完了済みとは表示しない。集計の元応募・求人に影響せず、再集計で修復する。
- `94_画像マスタ` のURL・取得状態はCSVの**全件再取込で再作成される**ため、取得URLを永続保持する設計ではない。初版の動作確認後、更新時のキャッシュ引継ぎを必要に応じて検討する。
