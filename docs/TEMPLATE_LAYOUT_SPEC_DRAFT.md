# Google Sheetsテンプレート設計 v0.2（初期レイアウトコード作成済み）

- 設計日：2026-10-16
- 対象：`valid-app-sheets`。**初期テンプレート生成用GASコードは作成済み。Google Sheets実体・CSV取込・集計は未作成**
- 確定前提：**コンテナバインドGAS**／空テンプレートをコピーして利用／CSVはブラウザ内処理して全件置換／RAW個人情報は保存しない（求人備考全文は許可）／基本分析は8年代列固定／カスタム3指標／結果を黙って省略しない全件表示
- 関連：[表示仕様](DISPLAY_SPEC_DRAFT.md)、[応募・求人保存列](JOINED_DATA_MODEL_DRAFT.md)、[CSV更新・復旧](CSV_IMPORT_UPDATE_SPEC_DRAFT.md)
- 現行Web版の参照：[valid-app](https://github.com/tsicb/valid-app)（分析軸・データ意味を継承、画面操作は別設計）

## 1. テンプレートの設計原則

1. **最短動線**：テンプレートを「コピー」→上部の `有効応募分析` メニューで「CSVを取り込む」→`40_基本分析` またはグラフ／カスタム分析を見る。index.html、report.html、中央共有設定は不要。
2. **閲覧用は5タブ**：基本分析／応募進捗／カスタム分析／TOP画像／Indeedタグ。詳細集計表を分析指標ごとに追加しない。
3. **編集用をまとめる**：`30_分析設定` と `31_マスタ編集` の2タブに人手入力を集約。多数のマスタを追加の常設タブとして分散させない。
4. **所有者を分離**：ユーザーが編集するセルとGASが書き込むセル、シート関数が展開するセルは重複させない。GASは日常更新時にシート自体を削除・再作成しない。
5. **列幅・行高・背景色・罫線の保持を優先**：初回セットアップでレイアウトを作り、以後の通常実行は必要な**値・数式・画像式だけ**更新する。表の行数増減でも既存書式をリセットしない。
6. **分析用の固定定義と表示ラベルを分離**：内部集計キーは機械用英字ID。ユーザーは日本語名称をプルダウンで選択。列参照は名前付き定義・ヘッダー検証等で管理し、表示名の変更に対応できるようにする。
7. **全件表示**：上位件数で打ち切らない。必要な行・列だけ末尾に追加する。スプレッドシート側の容量・時間制限で不可能なら処理前に説明し、黙って一部だけ表示しない。

## 3. セル配置ルールの共通仕様

- 表示タブの見出しは原則 `A1:L2`。ユーザーが編集する選択セルは明示的に設置する。
- **入力値セル**：薄い色＋データ入力規則で識別。**出力値セル**：背景色はユーザー変更を許容する。
- 処理時はヘッダー一致・タブ存在・書込許可範囲を先に検査する。手動で列を削除／入替された場合は破壊的な修復をしない。
- 表のセル色などは通常更新で保持。カテゴリーに意味を持たせる色は「行番号固定の塗り」よりも**条件付き書式**を基本とする。行が並び替わるため。
- 表の出力が少なくなったときは**前回出力矩形**と今回出力矩形の余剰分の`clearContent()`で値だけ消す。書式やユーザーの列幅・行高は消さない。
- 新しい行が必要になれば、必要数だけ**シート末尾に追加**する。可変表示領域の中間へ行を挿入しない（グラフ・参照・ユーザー書式のずれを防ぐ）。
- 初期化／レイアウト修復はメニューを分けて案内・確認を入れる。通常の集計ボタンで`clear()`や`clearFormats()`をしない。
- 空白のIDも有効な分析値の「0」と混同しない。データのない分析軸はプルダウン候補に表示しない。

- 左側の`A`列はラベル、`C:D`列は説明／確認メッセージ。A:D間の結合は最小限。

- バケット幅の初期値は**既存Web版の定義**と整合させてテンプレート作成時に設定する。未調査の値をこの設計書で捏造しない。
- 対象年齢とターゲット年齢を分ける。ターゲット率はターゲット応募数÷その行・列の総応募数。
- マスタ変更後や設定変更後は**「分析設定を反映」**で集計キャッシュを更新する。

### 右側：分析項目の表示設定（G:J）

| セル／範囲 | 内容 |
|---|---|
| `G4:J4` | 見出し：内部ID／分析項目名／表示ON／利用可能状況 |
| `G5:G37` | 既存Web版の表示定義33件の内部ID |
| `H5:H37` | 同33件の日本語ラベル |
| `I5:I37` | 表示ON/OFFチェックボックス（利用者入力） |
| `J5:J37` | 元データを見た利用可能判定（読取専用） |

- 表示ON/OFFとデータ利用可否は**別判定**。設定がONでも元データがない軸は候補に入れない。
- 既存Web版の「表示項目」は概要・基本・詳細・カスタムの区分を含む。**30分析軸と33表示項目は異なる集合**。給与区分のカスタム軸は給与下限項目との連動で取り扱う。
- `J`列の利用可能判定は期間・年齢フィルター前の保存済み元データから算定。期間条件で一時的に0件でも選択肢そのものを消さない。
- 閲覧用の分析表を消したり作ったりせず、表示OFFの場合は該当候補を外す／専用タブに「表示OFF」と明示。タブを自動削除しない。

## 6. `31_マスタ編集`（1タブ集約・提案）

`A1:L2`：タイトル／「ここは利用者が編集するマスタ。変更後に分析設定を反映」の説明。

同一タブで**横に3ブロック**を作る。行の追加は範囲末尾の空白セルへの追記で行い、表全体の行挿入・全行ソートを前提にしない。

| テーブル | ヘッダー行 | 入力開始 | 項目 | 集計への影響 |
|---|---|---|---|---|
| 仕事名KW | `A4:C4` | `A5:C` | A=KW文字列、B=有効、C=補足（任意） | KW別・フルKW別。**マスタ上からの並び順がKW優先度** |
| 企業ID | `E4:G4` | `E5:G` | E=企業ID、F=表示名、G=有効 | 企業ID別の表示名。IDは文字列 |
| Indeedタグ名 | `I4:K4` | `I5:K` | I=タグコード、J=表示名、K=有効 | タグコード別名称。コードは文字列 |

- マスタの変更時に`20`や`93`の正本データは**原則再取込しない**。GASの「分析設定を反映」でマスタから再集計する。
- 同じKW／企業ID／タグコードが重複する場合の優先規則は**エラーまたは警告を出す**方針（重複を黙って採用しない）。
- 保存先と閲覧タブを増やしたくないため1タブ集約。**検証で行挿入・範囲ソートの誤操作が多い場合は、マスタ別3タブに分割し初期状態で非表示にする案へ変更可能**。
- 画像URLの手動補正はこのマスタに混ぜず、`94_画像マスタ`側／専用操作を後続設計で決める。
- コードや先頭ゼロ付き値を数値化しない。数式に解釈され得る文字列は安全に扱う。
- 初期マスタは既存Web版の公開可能な共通マスタに合わせた初期値を入れる方向。利用者が編集した内容はCSV更新で消さない。

## 7. `20_突合データ`／`93_求人分析マスタ`

### 20_突合データ

- `A1:W1`：保存列設計書の**23列**ヘッダー。データ`A2:W`。**1行目を固定**し、データフィルターを利用可能にする。
- 値は**応募1件＝1行**。氏名・メール・電話・詳細住所・応募者の自由記述は保存しない。
- 日付列はGASで入力検証し、スプレッドシート上は日付として扱える型（`yyyy-mm-dd`表示）にする案。仕事番号・企業IDは文字列。
- `S:V`の代表的な求人属性は**確認用コピー**。`93`を分析の正本とする。表示用の手修正は原則反映されず、次回全件更新で上書き。
- 求人備考**全文**は`93`のL列へ保存し、`20`の応募ごとに重複コピーしない。
- データを並べ替えられても参照を行番号で結ばず、**求人参照IDでJOIN**する。次回更新時は全体を更新してよい。
- 書式変更は残すが、**データ自体のセル編集は対象外**。行色はデータの並び替え・全件再生成で別カテゴリへ移る可能性がある。

### 93_求人分析マスタ

- `A1:T1`：保存列設計書の**20列**ヘッダー。データ`A2:T`、1求人=1行、通常非表示。
- `L`列「求人備考」は**全文保存**。1行目分析は別途集計関数で抽出する。
- `A`列「求人参照ID」は一意。求人CSVありの属性を優先し、応募CSV内求人情報で互換項目のみ補完。
- `JOB_CSV`と`APPLICATION_EMBEDDED`を区別し、後者から給与・画像・Indeedタグなどを推測しない。

### 94_画像マスタ

- `A1:E1`：画像ファイル名／公開求人候補ID／画像URL／取得状態／最終取得日時（5列）。
- 同じ画像に複数の公開求人候補がある場合、候補IDの保存表現（1セルのリストか、子表を持つか）は実装検討。取得に失敗しても分析自体は成功扱い。

## 8. `40_基本分析`（固定12列／即時切替）

| セル／範囲 | 内容 |
|---|---|
| `A1:L2` | 画面タイトル |
| `A3` | 「分析項目」ラベル |
| `B3` | **プルダウン：基本分析の項目**。利用可能＋表示ONだけを候補 |
| `D3` | 元データ範囲：全応募／求人情報あり／求人CSV突合済み |
| `H3` | 集計条件の短い説明 |
| `B5` | 分析対象応募数 |
| `D5` | ターゲット応募数 |
| `F5` | ターゲット応募率 |
| `H5` | 最終反映日時 |
| `A8:L8` | **固定ヘッダー** |
| `A9:L` | **カテゴリ全件の集計値**。選択プルダウンからキャッシュ参照しGAS実行なし |

`A8:L8`の列は**変更不可（確定済み）**：

| A | B | C | D | E | F | G | H | I | J | K | L |
|---|---|---|---|---|---|---|---|---|---|---|---|
| 分類 | 総応募数 | ターゲット応募数 | ターゲット率 | 10代 | 20代 | 30代 | 40代 | 50代 | 60代 | 70代 | その他 |

`90_基本集計キャッシュ` の列は`A=指標ID`、`B=カテゴリ`、`C=総応募`、`D=ターゲット応募`、`E=率`、`F:M=年代8列`とし、**1指標ずつ縦に全件連結**する。

`A9`からの表示式（**実装前の構文例**）：

```gs
=IFNA(FILTER('90_基本集計キャッシュ'!B2:M,
             '90_基本集計キャッシュ'!A2:A=$B$3),
      "現在の条件では集計対象データがありません")
```

- 上式は`B3`を内部IDとして扱う**説明用**。実際の`B3`は日本語ラベルとし、`92_運用管理!G2:H`の対応表で内部IDへ引く。実装時に`XLOOKUP`または同等の検索式へ置換する。
- 配列の**展開先`A9:L`は常に空き領域**とし、式のある`A9`以外へGAS・ユーザーが値を記入しない。下部に合計行や注記を置かない（`#REF!`の原因になる）。
- `FILTER`は条件一致行を返す。全件表示できる限り件数で打ち切らず、0件時は`IFNA`で専用メッセージを出す。表示ラベルと内部IDの変換表は`92_運用管理!G2:H`（G=内部ID、H=表示名）を使う予定。
- 条件付き書式の追加・書式コピーで**配列式を上書きしない**。ユーザーがセル色や列幅を変えても再集計で戻さない。
- `90`の集計キャッシュは「設定を反映」「CSV全件更新」時だけ書き換える。B3プルダウンの切替では再集計せず即時切替。
- 複数の基本指標がデータ0件／設定OFFの場合は、その候補を選択不可にする。すでに選択していた指標がOFFになったら選択を安全な有効候補へ切り替え、通知する。
- **全件スピルに必要な行数**は、CSV更新・設定反映時に先に`40`の行数を必要量へ拡張する。基本分析の切替時は最大カテゴリ行数分の行を確保済みにする。固定の打切り件数は設けない。

| 範囲 | 内容 |
|---|---|
| `A1:L2` | 画面タイトル |
| `B3` | 日別／累積の表示モード（`30!B28`と連動、入力の正本は設定シート） |
| `D3` | 最新月の応募数 |
| `F3` | 最新月の着地予測 |

| `A6:L24` | **コンボチャートの配置候補**：最新月は棒、比較月は線、予測は線または別の注記 |

- 31日分×対象系列を`91_進捗キャッシュ`に保持する。チャートはGASで毎回削除・再作成せず、参照データを更新する。
- Web版の最新月着地予測・日別／累積・過去月比較を継承。Google Sheetsのコンボグラフで棒＋線が難しい場合、**最新月棒と比較月線の2チャート構成**に切り替えるが集計指標は維持する。
- 日別／累積の切替を`B3`で直接行うか設定タブを正とするかは最終UIで統一し、同じ項目を複数箇所で独立編集させない。
- グラフ対象系列数は`30!B30`で決める。**これは表示上限でなく可読性設定**であり、元応募データや月別一覧には制限をかけない。

## 10. `42_カスタム分析`（可変列数、実行型）

| セル／範囲 | 内容 |
|---|---|
| `A1:L2` | 画面タイトル |
| `B3` | 行軸1（必須） |
| `B4` | 行軸2（任意） |
| `B5` | 行軸3（任意） |
| `E3` | 列軸（必須） |
| `E4` | 指標（**応募数／ターゲット応募数／ターゲット率**） |
| `A8` | 「カスタム分析を実行してください」／最新反映日時／軸変更未反映等の状態 |
| `A12:D12` | 固定の行軸1／行軸2／行軸3／行合計のヘッダー |
| `E12:` | 指定された列軸の全カテゴリ。列数は可変 |
| `A13:` | クロス集計データ、全行・全列を出力 |

- 行軸は最大3、列軸は1。行・列での同一軸重複は禁止。**年月は行にも列にも使用可能**。
- 基本分析は年代列固定だが、カスタムは自由な年齢・軸・月の組合せを許可。
- 行合計・列合計・総合計も**選択中の指標の意味に従う**。率を集約する際に比率の単純平均は禁止（分子・分母から再計算）。
- **軸セル変更だけでGAS重処理をしない**。上部メニューの「カスタム分析を実行」を押した時だけ`A12`以降の値を更新。必要な行・列の全件を出す。
- 可変表の出力は、`A12`から開始する**連続した矩形**。列が減少した場合は前回余剰領域の**内容だけ**クリアし、背景・列幅は残す。
- データがゼロの時と軸が無効な時は別メッセージ。物理上限を超える時は**省略せず中止・エラー表示**。

## 11. `43_TOP画像`／`44_Indeedタグ`

### 43_TOP画像

- `A1:L2`タイトル、`B3`集計条件、`H3`画像URLの取得状況。
- `A8:N8`固定ヘッダー（14列）：**画像**、ファイル名、対象求人数、総応募数、ターゲット応募数、ターゲット率、10代／20代／30代／40代／50代／60代／70代／その他。通常更新では列構成を変えない。
- データ`A9:`以降：**画像ファイル名単位で全件**。画像なしは独立カテゴリ。
- サムネイル列のみ大きい行高・列幅を初期設定。**画像は既存WorkerでURL解決**し、取得できなければファイル名と数値だけを表示。
- `IMAGE(url)`を使う場合、URLを安全に検査し、取得失敗・大量画像の負荷を確認。画像表示をOFFにできても**集計行はすべて表示**し、画像失敗を集計失敗扱いにしない。
- 大量画像の処理時にGASが毎行の行高を書き換えることはしない。既存のユーザー変更を保持。

### 44_Indeedタグ

- `A1:L2`タイトル、`B3`集計条件。
- `A8:N8`固定ヘッダー：タグコード／タグ名称／対象求人数／総応募数／ターゲット応募数／ターゲット率／10代～70代＋その他。
- データ`A9:N`以降：**全タグ**。1応募に複数タグが付く場合、各タグにカウント。**タグ別件数の総和は全応募数と一致しない**旨を常時表示。
- マスタ変更後は`31_マスタ編集`の名称を反映して再集計。未登録コードには「コード（名称未登録）」。
- 求人CSV突合済み応募のみを対象とし、`APPLICATION_EMBEDDED`からIndeedコードを捏造しない。

## 12. 更新関数・セル所有権の契約

| 操作／関数（仮名） | 入力 | **触ってよい範囲** | **触ってはいけないもの** |
|---|---|---|---|
| `setupTemplate()`（初回専用） | 空シート | シート作成・ヘッダー・初期書式・プルダウン・チャート配置 | 既存のカスタマイズ済みシートを無条件に初期化しない |
| `openCsvDialog()` | ユーザーCSV | HTMLでRAW処理、保存前検証、`20`・`93`・`94`・キャッシュ・ホームの値 | `30`のユーザー設定・`31`のマスタ・既存の書式 |
| `applySettings()` | `20`・`93`・`94`＋`30`・`31` | `90`・`91`・閲覧集計・ホーム状態 | CSV正本、設定の入力値、マスタ |
| `runCustomAnalysis()` | 保存済み明細・マスタ・`42`の入力 | `42!A8`状態／`A12:`出力値 | `42!B3:B5`、`E3:E4`、書式 |
| `refreshTopImages()` | `94`の候補ID | `94`の画像URL・取得状態／`43`画像式 | 応募・求人の正本、設定・マスタ |
| `onOpen()` | シートを開く | メニュー追加・必要な軽い状態表示 | 大量データの自動再計算 |
| `onEdit(e)` | 設定・マスタ編集 | 軽量な「変更未反映」状態更新（必要なら） | CSV取込、JOIN、画像Worker大量呼出 |

- 個々の範囲は**入力／出力／数式／初期化専用**という所有権を持たせ、GASで範囲指定する際に誤上書きを防ぐ。
- `20`／`93`／`94`／`90`などの内容更新は**必要な新データを検証し前回復旧方法を確保してから**実行。途中失敗で`READY`にならないよう状態遷移する。
- `31`のマスタを編集しただけでは応募CSV全件アップロードは不要。ただし、RAW全文から新たに別の属性を算出する機能追加は再取込が必要。
- 配布後の各テンプレートはコピーされたバインドGASとして独立。コードは本GitHubリポジトリを正本とし、初版は中央配布機構を作らない。

## 13. 実装に入る前の検証項目

1. `FILTER`の配列展開の速度・範囲・書式維持。**大量カテゴリでプルダウン切替時の`#REF!`や速度低下がないか**。
2. 基本分析キャッシュを全件連結する際、基本指標ごとの日本語表示名・内部ID・候補リストが一致するか。
3. `31_マスタ編集`を3ブロックにまとめた構成が、行挿入・フィルタ・貼付けで使いにくくないか。
4. Google Sheetsの埋込グラフで最新月棒＋比較線＋着地予測を維持しながら、チャートの位置・色・設定を更新時に崩さないか。
5. TOP画像サムネイルが多い場合の再計算速度・取得失敗・表示ON/OFFと行高保持。
6. カスタム分析の全件出力で既存の列幅・セル色を保持し、列が減っても古い値が残らないか。
7. 既存Web版で使う33表示項目定義と30分析軸のデータ利用可能性が正確か（`給与区分`は例外扱い）。
8. ターゲット率＝ターゲット応募数／総応募数、ゼロ分母時の扱い、年代列の「その他」に80代以上／年齢不明を含む互換性。
9. GASの認証後、コピー先の任意マイドライブフォルダで動作するか。元テンプレートのSpreadsheet ID固定値が残っていないか。
10. CSV更新の途中停止・復旧・元データの安全性は[全件更新設計](CSV_IMPORT_UPDATE_SPEC_DRAFT.md)に沿ってテストする。
