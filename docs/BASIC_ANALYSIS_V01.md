# 基本分析 v0.1 実装・導入手順

既存Web版からのデータ正規化・取込は変更せず、保存済み `20_突合データ` と `93_求人分析マスタ` から基本集計を計算する。

## 実装範囲

- 20項目：年代、対応状況、応募年月、媒体、企業ID、性別、氏名文字種、居住都道府県、職種、雇用形態、勤務地名・都道府県・居住地一致、募集背景、曜日、月内応募日、応募時間帯、メイン画像有無、動画有無、求人備考1行目。
- `30_分析設定`：開始日・終了日（B5:B6）、対象年齢（B9:B10）、ターゲット年齢（B13:B14）に対応。年齢設定の両端が空欄の場合は全応募をターゲット扱い。対象年齢に制限がある場合、年齢不明を除外。
- `90_基本集計キャッシュ`に各分析結果を縦持ち保存し、`40_基本分析`のB3プルダウン変更で`FILTER`表示する。分類行は件数制限なし。
- `40_基本分析`固定列：分類・総応募・ターゲット応募・ターゲット率・10代～70代＋その他。
- 設定ONかつ保存済みデータに値がある項目だけプルダウンに表示する。
- CSV再取込不要。上部メニュー「有効応募分析 → 基本分析を再集計」を実行する。
- KW、給与下限帯、原稿文字数、画像枚数、Indeedタグ数、TOP画像別・Indeedタグ別の集計は**まだ未実装**。対応済みの20項目のみ有効。
- 月内応募日・応募時間帯は現時点では保存済みの値そのものによるグループ化。幅B17:B18を適用したバケット集計は次工程。

## 既存のシートへの配置

1. `gas/06_BasicCore.gs` と `gas/07_BasicSheet.gs` を新しく作成し、GitHub上の内容をそれぞれ貼り付ける。
2. `gas/01_EntryPoint.gs` を最新版へ全文差し替える（「基本分析を再集計」メニュー追加）。ほかのGASファイルの変更は不要。
3. Apps Scriptを保存し、スプレッドシートを再読込。
4. `有効応募分析 → 基本分析を再集計`を実行。現在のCSVが取込済みで`READY`であることが前提。
5. `40_基本分析`のB3で「職種別」「応募媒体別」などを選び、固定列の表が切り替わることを確認。
6. `30_分析設定`のターゲット年齢下限・上限を変更後、もう一度「基本分析を再集計」して数値が更新されることを確認。

**実Google Sheetsでの動作はまだ未検証**。まずコピーしたテスト用シートで確認する。
