## 実装範囲：基本分析29項目

従来の基本分析20項目に以下の9項目を追加した。

| 基本分析項目 | 集計対象 | 判定方法 | 設定 |
|---|---|---|---|
| 仕事名KW別 | 求人分析情報がある応募 | `31_マスタ編集`の**有効チェック済**KWを上から優先して1件選択、該当しなければ「（該当なし）」 | `31!A5:B` |
| 仕事名フルKW別 | 求人分析情報がある応募 | 有効KWの該当分を優先順で`＋`連結 | `31!A5:B` |
| 時給下限別 | 求人CSV突合済み、給与区分=時給 | 給与金額MINを指定幅の金額帯に集計 | `30!B19` |
| 日給下限別 | 求人CSV突合済み、給与区分=日給 | 同上 | `30!B20` |
| 月給下限別 | 求人CSV突合済み、給与区分=月給 | 同上 | `30!B21` |
| 年収下限別 | 求人CSV突合済み、給与区分=年収 | 同上 | `30!B22` |
| 求人原稿文字数別 | 求人CSV突合済み | 取込時に保存済みの求人原稿文字数を指定幅で集計 | `30!B23` |
| 求人画像枚数別 | 求人CSV突合済み | 求人画像枚数を指定幅で集計 | `30!B24` |
| Indeed求人タグ数別 | 求人CSV突合済み | Indeed求人タグ数を指定幅で集計 | `30!B25` |

**給与区分コード**はWeb版の `common-masters-v1.js` と同じ対応：`1=時給`、`2=日給`、`3=月給`、`4=年俸`、`5=年収`、`6=完全歩合制`、`99=その他`。**年俸（4）は年収（5）の集計へ混ぜない**。既に名称で保存されている場合にも対応する。

**区分の例**：
- 時給1,250円、幅50円 → `1,250-1,299円`
- 月給300,000円、幅50,000円 → `300,000-349,999円`
- 原稿文字数650、幅300 → `600-899文字`
- 画像3枚、幅2 → `2-3枚`
- タグ数7個、幅5 → `5-9個`
- 給与下限が空欄または0以下 → `（給与下限なし）`
- 画像枚数・タグ数が空欄 → 0として区分化

## 仕事名KWマスタ

`31_マスタ編集` の `A列=仕事名KW`、`B列=有効チェック`を使用。

例：`A5=物流、B5=ON`、`A6=配送、B6=ON`、求人名「物流配送スタッフ」の場合、単独KW=`物流`、フルKW=`物流＋配送`。大文字・小文字は区別しない。

**Sheets版の入力管理として「有効」チェックが必要**（Web版のKW一覧はチェック列を持たないため、ここはSheets固有のUI設計）。1件も有効KWがない場合はKW分析項目をプルダウンに出さない。キーワードの補足欄C列は集計に使用しない。

`31_マスタ編集` の `E列=企業ID`、`F列=表示名`、`G列=有効チェック`も基本分析の企業ID別表示に反映。表示名が登録されていない企業には`企業ID（名称未登録）`を表示する。**有効な企業表示名が1件もない場合**はWeb版に合わせて企業ID別の候補自体を表示しない。

これらのマスタの変更は、応募・求人CSVの再取込ではなく「基本分析を再集計」で反映する。

## 設定変更・未反映表示

`30_分析設定` の `B19:B25`（7つの数値区分幅）を、v0.2で実装済みの「設定変更あり・再集計未反映」の検知対象に追加した。さらに、有効KWと有効な企業ID表示名の変化も検知する。

無効のKWや企業情報、補足メモの変更は基本分析に影響せず、再集計フラグは立てない。各表示項目のON/OFFも従来どおり検知する。

ホームの`B8/B9`に表示する**最後に適用済みの期間と年齢条件**は維持する。

## 表示・データ取得上の注意

- `30_分析設定`I列の表示チェックがON、かつ対象応募がある分析項目だけが`40_基本分析`B3の候補になる。
- 求人CSV突合済みの判定は、`20_突合データ`の求人突合フラグと求人マスタ`JOB_CSV`ソースの両方が一致すること。応募CSV由来の求人情報（`APPLICATION_EMBEDDED`）を給与・画像・タグ数の集計へ混ぜない。
- 求人備考1行目は、従来どおりマスタの備考全文を必要時に切り出す。
- `40_基本分析`は固定の年代8列（10代～70代＋その他）。既存Web版の可変年代表示そのものは移植していない。
- `42_カスタム分析`、`41_応募進捗`、`43_TOP画像`、`44_Indeedタグ`の専用集計画面は**今回の対象外**。
- 応募媒体等の従来軸で空値を「（未設定）」「（不明）」に分類する場合がある。Web版の集計時カテゴリ処理に寄せたもの。
